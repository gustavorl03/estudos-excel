## 📚 Conteúdo por nível

### 🟢 Básico
Fundamentos do Excel para organização e análise inicial de dados.

| Pasta | Conteúdo |
|---|---|
| `01_formatacao_e_navegacao` | Formatação de células, atalhos e navegação |
| `02_formulas_basicas` | SOMA, MÉDIA, MÁXIMO, MÍNIMO, CONT.NÚM |
| `03_referencias_celulas` | Referência relativa, absoluta ($) e mista |
| `04_graficos_basicos` | Gráficos de barras, linhas e pizza |

### 🟡 Intermediário
Fórmulas de busca, tabelas dinâmicas e análise de dados.

| Pasta | Conteúdo |
|---|---|
| `01_se_e_operadores_logicos` | SE, E, OU, NÃO, SE aninhado |
| `02_procv_e_proch` | Busca vertical e horizontal |
| `03_procx` | Substituto moderno do PROCV |
| `04_tabela_dinamica` | Criação e configuração de tabelas dinâmicas |
| `05_filtros_avancados` | Filtros, classificação e segmentação |
| `06_formatacao_condicional` | Regras visuais baseadas em valores |

### 🔴 Avançado
Fórmulas complexas, Power Query e criação de dashboards.

| Pasta | Conteúdo |
|---|---|
| `01_indice_e_corresp` | Combinação ÍNDICE + CORRESP |
| `02_formulas_matriciais` | Fórmulas com arrays e CTRL+SHIFT+ENTER |
| `03_power_query_excel` | Importação e transformação de dados |
| `04_dashboard_excel` | Dashboard interativo com gráficos dinâmicos |
| `05_macros_basico` | Gravação e edição de macros simples |

### 🏆 Projetos Práticos
Planilhas completas aplicando os conhecimentos adquiridos.

| Projeto | Descrição |
|---|---|
| `controle_financeiro` | Planilha de controle de receitas e despesas |
| `analise_vendas` | Análise de desempenho de vendas com dashboard |

## 📝 Como os arquivos estão organizados

Como arquivos `.xlsx` são binários e não podem ser visualizados diretamente no GitHub, cada pasta contém um `notas.md` seguindo este padrão:

```markdown
## Tema: Nome do tema estudado

### O que aprendi
Descrição do que foi estudado nessa aula/prática.

### Fórmulas / recursos utilizados
- FÓRMULA() — para que serve e como usar

### Print do exercício
![print](print.png)

### Dicas e observações
Alguma dificuldade encontrada ou dica importante.
```
